# Capturas da proposta comercial

Os arquivos PNG já versionados nesta pasta pertencem à apresentação anterior ao redesign fotográfico iniciado em 21/10/2026. **Não utilizá-los como capturas da versão mais recente.**

A suíte automatizada `tests/browser/captures.spec.ts` produz capturas representativas com larguras desktop e mobile; a execução do GitHub Actions disponibiliza os novos PNGs em um artefato de workflow chamado `capturas-escola`.

Após conferir o resultado real no navegador, a seleção final pode substituir os PNGs antigos neste diretório. Nenhuma captura antiga foi rotulada como atual sem ter sido revalidada.
